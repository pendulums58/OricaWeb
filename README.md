# OricaWeb

[CyanPro_CardDB](https://github.com/pendulums58/CyanPro_CardDB) 를 읽어 카드 데이터베이스 사이트를 만든다.

**카드 데이터는 브라우저가 GitHub 에서 직접 받아 해석한다.** 카드를 push 하면
빌드를 기다릴 것 없이 사이트에서 새로고침만 누르면 보인다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `template/index.html` | 사이트 본체 |
| `template/decode.js` | 카드 해석기. 비트 필드와 효과 설명 꼬리를 읽는다 — **유일한 해석기** |
| `template/deck.js` | 덱 에디터. 매수 규칙·저장·공유·`.ydk` 입출력 |
| `config.json` | 어느 저장소·브랜치를 읽을지 |
| `types.extra.json` | CyanCore 오리지널 타입 비트 → 표시 이름 |
| `packs.meta.json` | 팩 표시 이름·발매일, 팩 코드 오타 보정 |
| `allocations.json` | ID 구간·카드군 코드 할당표 |
| `lflist.json` | 제한 규정. 카드 ID → 허용 매수 (0 금지 / 1 제한 / 2 준제한) |
| `icons/` | 속성·레벨 아이콘 (선택) |
| `build.py` | 원본 이미지를 webp 로 줄이고 사이트 파일을 `dist/` 에 모은다 |
| `stats/` | 듀얼 통계 수집기 (Cloudflare Worker + D1). 배포 방법은 그 안의 README |

## 데이터가 흐르는 길

```
CyanPro_CardDB ──(브라우저가 raw 로 직접)──> sql.js ──> decode.js ──> 화면
CyanPro        ──(엔진 헤더 raw)──────────────────────> 코드 일람
   │
   └──(CI, 3시간마다)──> webp 썸네일 ──> dist/img/
```

빌드는 **이미지만** 담당한다. webp 가 아직 없는 새 카드는 원본 이미지를 직접
불러오므로, 빌드가 늦어도 카드가 안 보이는 일은 없다.

## 화면

| 탭 | 내용 |
| --- | --- |
| 전체 카드 목록 | 모든 카드. 팩에 수록되지 않은 카드도 나온다 |
| 팩 목록 | 번호로 묶인 팩들 |
| 덱 에디터 | 덱을 짜고 브라우저에 저장한다. 공유 링크와 `.ydk` 로 주고받는다 |
| 코드 일람 | 엔진 헤더의 상수표. `constant.lua` 와 어긋나는 값은 경고한다 |
| 할당 현황 | ID 구간과 카드군 코드를 누가 쓰는지. 실제 카드와 대조한다 |
| 대전 통계 | 카드별 채용률·선택률·승률. `config.json` 에 `statsApi` 가 비어 있으면 탭이 나오지 않는다 |
| 덱 통계 | 레시피별 매치·듀얼 승률. 사이드 교체한 판을 1차전 레시피로 묶는다 |

## 팩의 기준

효과 설명 맨 끝의 `[POG1-AM001]` 번호로 묶는다. 번호가 없는 카드는 아직 팩으로
묶이지 않은 것으로 보고 팩 목록에 넣지 않는다 (전체 카드 목록에는 나온다).

효과 설명 꼬리는 이렇게 읽는다.

```
[시안색새벽]                  ← 첫 줄은 제작자
[태그 : 범용 | 단짝]          ← | 로 여러 개를 나눈다
[베드록 팩 - 리라이티드 ...]   ← 팩 이름
[RS01-AM001]                  ← 카드 번호
```

## 할당표

`allocations.json` 을 고치고 커밋하면 사이트에 반영된다. 쓰기 권한이 있는
사람만 고칠 수 있으므로, 별도의 계정 시스템 없이 GitHub 협업자 설정이
그대로 권한이 된다.

**ID 구간과 카드군 코드는 서로 묶이지 않는다.** 한 구간에 여러 카드군이 섞일
수도 있고, 한 카드군이 여러 구간에 걸칠 수도 있다.

사이트가 실제 카드와 대조해 아래를 잡아낸다.

- 예약 구간끼리 겹침
- 어느 구간에도 속하지 않는 ID 가 쓰이고 있음
- 카드군 코드 중복 / 공식 대역(`0x208` 이하) 침범
- 목록에 없는 setcode 가 카드에 박혀 있음

오리카 카드군은 `0x300` 부터 쓴다.

## 로컬에서 실행

```
python build.py
cd dist && python -m http.server 8000
```

`file://` 로 열면 안 된다. 카드 데이터는 GitHub 에서 받아오므로 인터넷이 필요하다.
이미지를 만들려면 CyanPro_CardDB 를 이 리포 옆에 두거나 `ORICA_PACK_DIR` 로 지정한다.

## 배포

`main` 에 push 할 때, 그리고 3시간마다 이미지를 다시 만든다.
카드 데이터는 빌드와 무관하게 항상 최신이다.
