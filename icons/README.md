# icons/

여기에 파일을 넣으면 사이트가 내장 SVG 대신 그 그림을 쓴다.
비어 있으면 내장 아이콘으로 그려지므로, 넣지 않아도 사이트는 정상 동작한다.

## 파일명

확장자는 `.png` / `.webp` / `.svg` / `.jpg` 중 아무거나.

| 파일명 | 쓰이는 곳 |
| --- | --- |
| `attr-earth` | 땅 속성 |
| `attr-water` | 물 속성 |
| `attr-fire` | 불 속성 |
| `attr-wind` | 바람 속성 |
| `attr-light` | 빛 속성 |
| `attr-dark` | 어둠 속성 |
| `attr-divine` | 신 속성 |
| `level` | 레벨 별 |
| `rank` | 랭크 별 (엑시즈) |

일부만 넣어도 된다. 없는 것만 내장 아이콘으로 채워진다.

## 권장 사양

- 정사각형, 64×64 이상
- 배경 투명 (png / webp / svg)
- 속성 아이콘은 넣는 순간 원형 배경과 색 입힘이 사라지고 그림이 그대로 나온다.
  그림 자체에 테두리나 광택이 있는 편이 잘 어울린다.

빌드할 때 몇 개를 찾았는지 알려주고, `dist/report.json` 의 `custom_icons` 에도 기록된다.
